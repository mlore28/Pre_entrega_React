# Boss-it

Catálogo de tecnología con detalle de producto y carrito de compras, desarrollado con React y Vite.

## Requisitos

- Node.js 20.19+ o 22.12+
- npm

## Desarrollo

```sh
npm ci
npm run dev
```

## Validación y compilación

```sh
npm run lint
npm run build
npm run preview
```

El catálogo vive en `public/productos.json` y contiene tres productos con ilustraciones SVG locales. La navegación usa hash para funcionar en hosting estático y las rutas de recursos son relativas para admitir la publicación en GitHub Pages.# Nébula Tech
